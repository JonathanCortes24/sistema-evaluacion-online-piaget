Funcionalidades

¿Qué permite realizar?

Una solución que integra el proceso de evaluación y la revisión de información académica en una misma plataforma.

01

Acceso validado

Identificación del estudiante y selección de su curso antes de acceder a las evaluaciones disponibles.

02

Evaluaciones en línea

Interfaz para responder evaluaciones digitales con distintos tipos de preguntas.

03

Seguimiento docente

Consulta de registros, filtros y resultados para apoyar el seguimiento del proceso académico.

Tecnologías

Herramientas utilizadas

El proyecto combina tecnologías web con servicios de Google para implementar la lógica de evaluación y el almacenamiento de información.

Google Apps Script Google Sheets HTML5 CSS3 JavaScript GitHub
